# Branch Rename Assistant

> Safely rename branches and update local references and scripts.

## Overview

Branch Rename Assistant helps you rename branches and keep local references and scripts in sync without leaving your IDE. It adds a dedicated tool window for searching and navigating your entries, plus a **Tools** menu action to open it on demand. Settings are stored per project.

## Installation

1. Open **Settings → Plugins → Marketplace**
2. Search for **"Branch Rename Assistant"**
3. Click **Install** and restart the IDE

**Requirements:** Any IntelliJ-based IDE 2023.2+

## Features

Branch Rename Assistant is free to use, with an optional paid Pro tier.

### Free Tier
- Time-saving in-IDE workflow
- Search and quick navigation
- JetBrains-native UI components
- Project settings persistence

### Professional Tier
- Advanced usage limits
- Templates
- Export / import
- Team workflows

The Pro tier is a paid upgrade (3.90/month).

## Configuration

**Settings → Tools → Branch Rename Assistant**

| Setting | Default | Description |
|---------|---------|-------------|
| Max entries | 200 | Maximum number of entries kept in the list |

## Tool Windows

### Branch Rename Assistant
- **Location:** right tool window panel
- **Content:** a scrollable list of entries with a search field at the bottom. Typing filters the list live, matching on entry name or value (case-insensitive), most recently updated first.

## Actions

| Action | Location | Description |
|--------|----------|-------------|
| Open Branch Rename Assistant | **Tools** menu | Opens and focuses the Branch Rename Assistant tool window |

## FAQ

**How do I open it?**
Use **Tools → Open Branch Rename Assistant**, or click the **Branch Rename Assistant** tab on the right edge of the IDE.

**Is it free?**
Yes. Core functionality is free; the optional Pro tier adds templates, export/import, higher usage limits, and team workflows.
